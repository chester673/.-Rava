# RAVA - Smart Robot Project

RAVA is a smart robot project built around the ESP32-S3-N16R8 microcontroller with an OV3660 camera module and a separate A7670E 4G modem.

## Hardware Components
- **Microcontroller**: ESP32-S3-N16R8
- **Camera**: OV3660
- **Modem**: A7670E 4G (separate module)

## Goals
- Web camera viewing over the internet
- Online AI capabilities
- Android control application

## Status
**Work in Progress**

Hardware and software integration is not yet verified. This project is still under active development.
